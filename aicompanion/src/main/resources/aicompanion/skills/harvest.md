# Harvest
Harvest mature crops from the farm and replant so it keeps producing.

## Required tools
- A hoe (any tier) — only needed if a farmland block has reverted to bare dirt; re-till it before replanting.
- Keep seed to replant: wheat drops seeds when harvested; carrots, potatoes, and beetroot replant from the harvested item itself.

## Steps
- Go to the farm. If you don't know where it is, ask the owner.
- Harvest only fully-grown crops — golden/brown wheat, full-size carrots/potatoes/beetroot. Leave young (green) crops to keep growing.
- Right after breaking each mature crop, replant the same crop on that block. Farmland stays tilled after harvest, so normally you just replant; only if the block turned back to dirt, till it with the hoe first, then plant.
- Pick up all drops. Replanting comes first — keep enough seed to refill the whole field; the surplus is the yield.
- Don't jump on the farmland (jumping tramples it back to dirt).
- When the field is fully harvested and replanted, return to the owner and report what you gathered. If stuck for over a minute, stop and say what blocked you.
